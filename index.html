Solar irradiance on a running body, simulated in Unity

Nobuteru Takeshita, Kenji Araki, Kensuke Nishioka, Yasuyuki Ota · University of Miyazaki

Body colour = point irradiance01000 W/m²
01 · 36 s

Normal view → irradiance heat map

The runner on a coastal road in Honolulu, then the same scene with every point on the body coloured by the sunlight it receives.

02 · 32 s

City run, ray-traced every 0.1 s

As the runner moves, the body is re-oriented and shaded by buildings, trees and itself, so the colour map changes with each stride.

03 · 35 s

Run → tired, bent over → run again

The same place and the same sun, but a different posture gives a different irradiance on the body, and so a different power output.
